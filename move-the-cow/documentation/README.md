# Move-the-Cow Documentation

This folder contains developer-facing documentation for project structure, coding conventions, and local workflow.

## Documents
- `architecture.md` — module boundaries and responsibilities.
- `code-style.md` — JavaScript/CSS/HTML style conventions.
- `contributing.md` — how to add code and keep structure consistent.
- `testing.md` — manual test approach for current scope.
- `requirements.md` — versioned mirror of gameplay requirements from Issue #2.
- `requirements-source.md` — source-of-truth and sync policy for requirements.

## Local workflow
- Install dependencies: `pnpm install`
- Start dev server: `pnpm dev`
- Build: `pnpm build`
- Preview build: `pnpm preview`

## Scope note
Ticket #3 focuses on code structure and style. Gameplay requirements remain the source of truth in GitHub Issue #2.
