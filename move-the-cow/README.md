# move-the-cow

Vanilla JavaScript game project with Tailwind CSS and Vite.

## Local development

```bash
pnpm install
pnpm dev
```

Then open the local URL shown by Vite (typically `http://localhost:5173`).

## Build

```bash
pnpm build
pnpm preview
```
