# Visual Regression Workflow (Kairos)

This document explains how to capture and compare the app UI against the standalone mockup.

## Snapshot tests included
- App frame: `kairos-app-hero-*`
- Mockup frame: `kairos-mockup-reference-*`

Both are generated by:
- `tests/e2e/visual-regression.spec.ts`

## Commands

### Run visual tests
```bash
pnpm test:visual
```

### Run visual tests in headed mode (recommended for review)
```bash
pnpm test:visual:headed
```

### Update visual baselines (when intentional UI changes are made)
```bash
pnpm test:visual:update
```

## Snapshot files location
Playwright stores baseline snapshots under:

```txt
tests/e2e/visual-regression.spec.ts-snapshots/
```

Typical files:
- `kairos-app-hero-chromium-darwin.png`
- `kairos-mockup-reference-chromium-darwin.png`

(Platform suffix may vary by OS/browser project.)

## Manual side-by-side compare
1. Open the snapshot folder in Finder.
2. Open both app and mockup snapshot images.
3. Compare:
   - overall layout centering
   - timer typography scale/weight/spacing
   - status line treatment (`Phase` line)
   - visual density of controls/chrome
   - color feel (background/foreground/accent)

## Notes
- These tests are currently for visual reference and baseline tracking.
- Keep feature behavior unchanged while doing visual-only tuning.
- If differences are intentional, run `pnpm test:visual:update` and commit updated snapshots.
