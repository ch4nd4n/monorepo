# Voice-Controlled Workout Clock

A frontend-first app for running workout timers using voice commands.

## Current Status
Planning phase only. No implementation yet.

## Scope (Phase 1)
- Define product requirements
- Set up docs and contributor guidance
- Run a "grill me" clarification session before coding

## Planned Product Direction
- **Primary UX:** Hands-free workout timing via voice commands
- **Initial platform:** Web frontend
- **Future phase:** Backend API for persistence, profiles, workout templates, and analytics
